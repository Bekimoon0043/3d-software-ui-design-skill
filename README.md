# 3D Software UI Design Skill

A Grok skill for designing professional user interfaces for 3D modeling, CAD, sculpting, animation, and spatial software.

## What it covers
- Viewport-first layouts
- Blender UI architecture (deep dive)
- Patterns from Cinema 4D, Maya, 3ds Max, Fusion 360, FreeCAD
- Interaction conventions (navigation, selection, gizmos)
- Usability principles for complex 3D tools

## Usage
Place the `3d-software-ui-design` folder in your Grok skills directory (`~/.grok/skills/` or equivalent). The skill will activate on requests about 3D software interfaces, CAD UI, viewport UX, Blender-like layouts, etc.

## Structure
```
3d-software-ui-design/
├── SKILL.md
```

Created for building better software for 3D designers.
