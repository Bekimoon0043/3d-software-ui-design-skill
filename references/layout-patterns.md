# Layout Patterns from Major 3D Software

## Blender
- Extremely flexible area system: any region can be split, joined, or changed type.
- Workspaces (tabs at top) switch entire screen layouts (Modeling, Sculpting, UV, Shading, Animation, etc.).
- Properties Editor (N-panel or right sidebar) is context-sensitive and tabbed.
- Tool shelf on left (T), properties on right (N).
- Pie menus and search (F3) reduce reliance on permanent UI.
- Outliner for hierarchy + Collections system.
- Strength: maximum customization and screen efficiency for experts.
- Weakness: steep learning curve for complete beginners.

## Cinema 4D
- Classic managers: Object Manager (hierarchy), Attribute Manager (properties), Material Manager, Timeline.
- Command palette / Commander for quick access.
- Viewport-centric with floating or docked toolbars.
- Strong visual consistency and clean default layout.
- Good balance of density and clarity.

## Maya
- Shelf system for custom tool buttons.
- Outliner + Channel Box / Attribute Editor combination is iconic.
- Hotbox (spacebar) for radial access to menus.
- Marking menus for fast context actions.
- Highly scriptable and customizable via MEL/Python.

## 3ds Max
- Command Panel on the right (Create, Modify, Hierarchy, Motion, Display, Utilities).
- Modifier stack is central to the workflow.
- Traditional menu + floating toolbars.
- Quad menu (right-click) for context actions.

## Fusion 360 / Modern CAD
- Ribbon or adaptive toolbar at top.
- Browser (feature/history tree) on left.
- Timeline at bottom showing construction history.
- Contextual toolbars that appear near the cursor or selection.
- Clean, modern aesthetic with strong focus on parametric history.

## FreeCAD
- Workbench system (switch entire tool sets).
- Combo View (tree + properties).
- Traditional menu + toolbar strips.
- Good free reference for CAD-style layouts.

## Common Winning Patterns
- Named, switchable workspaces or workbenches.
- Context-sensitive properties that update instantly.
- Hierarchy/outliner always available and searchable.
- Persistent but collapsible tool shelves.
- Global search / command palette.
- Saveable custom layouts per user or per project type.
